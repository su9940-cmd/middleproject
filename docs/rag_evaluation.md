# RAG 검색 품질 평가

> 통합 참고: 아래 수치는 SOP와 법령을 하나의 혼합 검색으로 평가한 기존 결과입니다.
> 운영 검색은 작업 가능한 SOP를 보장하기 위해 SOP·법령 예산을 분리했으므로,
> 최종 발표 수치로 사용하기 전 `scripts.compare_chunking`을 다시 실행해야 합니다.

산업 안전 문서(설비별 SOP + 산업안전보건기준에 관한 규칙 조문)에 대한
RAG 검색 파이프라인의 성능 평가 및 청킹 전략 비교 결과입니다.

## 1. 개요

- **대상 문서**: 설비 SOP 4종(압축기·펌프·반응기·저장탱크), 산안법 조문 8종
- **임베딩 모델**: `jhgan/ko-sroberta-multitask`
- **벡터스토어**: Chroma (cosine 거리 기반)
- **검색 필터**: `manual_id`(설비 ID) 기준 설비별 문서 격리
- **법령 인덱싱**: 각 조문을 연결된 설비별로 복제 저장하여 설비 필터와 호환

## 2. 평가 방법

평가 질문셋(`data/sop/rag_평가_질문셋.md`)의 총 38개 질문을 사용합니다.

- **SOP 질문**: 검색된 청크의 **절 번호**가 정답 절과 일치하는지 확인
- **법령 질문**: 검색된 문서의 **조문 번호(art)**가 정답 조문과 일치하는지 확인
- **교차 검색 표**: 기대 동작이 서술형이라 자동 채점에서 제외

### 지표 정의

- **Recall@3**: 상위 3개 검색 결과 안에 정답이 하나라도 포함되면 성공
- **MRR (Mean Reciprocal Rank)**: 정답이 처음 등장한 순위의 역수 평균
  (1위면 1.0, 2위면 0.5, 3위면 0.33)

## 3. 청킹 전략 비교 결과

| 전략 | Recall@3 | MRR | 청크 수 |
|------|:--------:|:---:|:------:|
| section | 0.868 | 0.702 | 51 |
| **fixed_512_50** | **0.895** | 0.702 | 73 |
| fixed_1024_100 | 0.868 | 0.702 | 54 |

- `section`: `##` 헤딩 단위 분할(SOP), 조문 단위(법령)
- `fixed_512_50`: 512자 고정 분할, 50자 오버랩
- `fixed_1024_100`: 1024자 고정 분할, 100자 오버랩

## 4. 결과 해석

- **Recall@3 기준 최고 성능은 `fixed_512_50`(0.895)** 입니다.
  조문을 잘게 나누면 특정 항(項) 단위 매칭이 잘 되어, 기존 miss였던
  압축기-펌프 연결 조문(제93조) 케이스가 상위에 검색된 것으로 보입니다.
- 단, **MRR은 세 전략 모두 0.702로 동일**합니다.
  top-3에 넣는 능력(Recall)은 512가 약간 낫지만, 순위 품질(MRR)은 차이가 없습니다.
- `fixed_512_50`은 청크 수가 73개로 `section`(51개) 대비 약 43% 많습니다.
  청크가 늘면 저장·검색 비용이 증가하고, 한 조문이 여러 조각으로 흩어져
  검색 결과에 같은 문서의 파편이 중복될 수 있습니다.

### 결론

성능만 보면 `fixed_512_50`이 우세하나 차이는 약 1문항 수준이며 MRR은 동일합니다.
**성능과 효율의 균형** 관점에서는 청크 수가 적고 문서 구조가 보존되는
`section` 전략이 합리적입니다. 최고 Recall이 목표라면 `fixed_512_50`을 사용합니다.
