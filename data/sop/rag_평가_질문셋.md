# RAG 검색 품질 평가 질문셋

청킹 실험(512/오버랩50 vs 1024/오버랩100 등) 비교표의 기준이 되는 평가셋이다.
Recall@3와 MRR을 측정할 때 아래 정답 매핑을 정답지로 사용한다.

질문은 SOP 문서의 표현을 그대로 베끼지 않고 현장 작업자의 구어체로 작성했다.
문서 표현을 그대로 쓰면 검색 성능이 실제보다 과대평가되기 때문이다.

## 교차 검색 테스트 (필터링 검증용)

`manual_id` 필터가 제대로 작동하는지 확인하는 항목이다.
필터 없이 검색하면 설비 유형이 다른 문서가 상위에 올라올 수 있다.

| # | 질문 | 기대 동작 |
|---|---|---|
| X1 | 진동이 심할 때 어떻게 하나요 | 압축기와 펌프 문서가 모두 매칭됨. `manual_id` 필터로 하나만 반환되어야 함 |
| X2 | 잠금장치는 언제 부착하나요 | 4개 문서 모두 매칭됨. 필터 없으면 어느 설비 절차인지 불명확 |
| X3 | 재가동 전에 확인할 항목 | 4개 문서 모두 매칭됨. 예측 결과의 `manual_id`로 좁혀야 정확한 답이 나옴 |
| X4 | DCS 경보 이력은 어디서 보나요 | 압축기와 펌프 문서가 모두 매칭됨. `manual_id` 필터로 해당 설비만 반환되어야 함 |

**X1~X4가 이 프로젝트에서 `manual_id` 필터링이 필요한 이유를 보여주는 사례**이므로,
발표의 RAG 섹션에서 필터 적용 전후 검색 결과를 비교해 제시하면 설득력이 높다.

## 산안법 문서 평가 질문 (팀원 4/5 추가 작성분)

산안법 벡터스토어가 구축되었으므로 아래 질문으로 `doc_type` 필터 검증을 수행한다.
`doc_type: law` 필터로 SOP와 법령이 분리 검색되는지 확인하는 것이 목적이다.

| # | 질문 | 정답 조문 | expected_doc_id |
|---|---|---|---|
| L1 | 정비 작업 중 갑자기 기계가 켜지지 않게 하려면 법적으로 뭘 해야 하나요 | 제92조 (운전정지·잠금·표지) | law_ind_safety_rule_art92 |
| L2 | 밀폐공간 들어갈 때 법에서 요구하는 조치가 뭔가요 | 제619조 (밀폐공간 작업 프로그램) | law_ind_safety_rule_art619 |
| L3 | 밀폐공간이라는 게 법적으로 어떻게 정의되나요 | 제618조 (정의) | law_ind_safety_rule_art618 |
| L4 | 인화성 가스 있는 곳에서 쓰는 전기 기구는 어떤 걸 써야 하나요 | 제311조 (폭발위험장소 전기 기계·기구) | law_ind_safety_rule_art311 |
| L5 | 화기 작업할 때 감시자를 꼭 둬야 하나요 | 제241조의2 (화재감시자) | law_ind_safety_rule_art241_2 |
| L6 | 화재 위험 있는 작업 할 때 지켜야 하는 게 뭔가요 | 제241조 (화재위험작업 준수사항) | law_ind_safety_rule_art241 |
| L7 | 회전체 방호 덮개는 법적 의무인가요 | 제93조 (방호장치의 해체 금지) | law_ind_safety_rule_art93 |
| L8 | 정전기로 불날 위험 막으려면 법에서 뭘 하라고 하나요 | 제325조 (정전기로 인한 화재 폭발 방지) | law_ind_safety_rule_art325 |

> L1~L8은 모두 `doc_type: law` 필터가 적용된 상태에서 법령 청크만 상위에 오는지 확인한다.
> 예컨대 L1("기계가 켜지지 않게")은 SOP의 잠금·표지 절차와도 표현이 겹치므로,
> 필터가 없으면 SOP 청크가 법령 청크보다 상위에 올 수 있다.
> 이 경우가 `doc_type` 필터의 필요성을 보여주는 사례가 된다.

## 측정 방법

각 질문에 대해 상위 3개 청크를 검색한 뒤:

- **Recall@3** — 정답 섹션(또는 정답 조문)이 상위 3개 안에 포함된 질문 비율
- **MRR** — 정답 섹션이 몇 번째로 나왔는지의 역수 평균

청킹 설정별로 위 두 지표를 표로 비교하면 지침서 7번의 RAG 요구사항
"청킹 크기·오버랩 최소 2가지 이상 실험 → 검색 품질 비교표 제시"를 충족한다.

정답 섹션이 복수(예: "6. 원인 점검 / 9. 안전 규정")인 경우,
둘 중 하나라도 상위 3개에 포함되면 Recall@3 정답으로 인정하고,
MRR은 둘 중 먼저 나온 청크의 순위를 사용한다.
